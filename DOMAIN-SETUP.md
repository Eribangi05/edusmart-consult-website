# Where the website lives

The public website is **https://www.edusmartconsult.rw**, hosted on Esicia cPanel (Apache). Pages are generated by `python build.py`, then the built files are uploaded to `public_html` (the `.htaccess` file in this folder's package handles HTTPS, clean URLs and caching).

* `www.edusmartconsult.com` and `edusmartconsult.com` forward to the `.rw` site with a Cloudflare redirect rule (301, path kept).
* `admin.`, `downloads.` and `sync.` on edusmartconsult.com are separate services (Render and Cloudflare R2) and are not part of the website upload.
* Email addresses end in `@edusmartconsult.rw` (webmail: https://edusmartconsult.rw:2096).
* The older Cloudflare Pages deploy of this repository is no longer the public site.
